# juku-library: the index

The papers that lead to the rules, kept word for word and never edited. Where an agreement itself was reached is its decision issue, linked below. Open a paper when a rule is about to change or its reason is in question. Never load one into a working session.

A later paper supersedes an earlier one, and the earlier stands as history. Papers are never edited, so their status lives here, not in them.

Each product keeps its own `<product>-library/` in its own repo, and opens it with the same kind of index when it creates it.

## Status words

- **Live**: in force or built.
- **Superseded**: a later record replaced it. The row names that record.
- **Legacy**: reference only. Never to be implemented.
