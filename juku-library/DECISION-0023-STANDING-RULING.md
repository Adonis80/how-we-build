# Decision 0023: an agreed, reviewed rule change counts as his ruling

**His standing ruling, 4 November 2026, 02:10, given in the Juku OS Project chat, word for word.**

```
My standing ruling: a change to how we build that Astra and the CTO agree, and that passes the independent review, counts as my ruling. Money, anything irreversible, and how things look still come to me.
```

**Why he gave it.** That night two rule changes (#308, #309) stopped to wait on his word, because `CHARTER.md` §13 admits an addition only on his ruling or the same failure in two separate product tasks, and the consultant's agreement was neither. He asked how the CTO could run without stopping; this was the answer he chose.

**Where it lives.** `library/changing-the-rulebook.md`, the gate paragraph, beside "nor does a change the Chairman rules himself". The consultant's agreement is cited, dated, in each changed text, so the reviewer, who never sees a pull request's body, can see it. The reviewer's verdict still gates every merge; a consensus never stands in for it (`library/consultant.md`).

**What it does not cover.** Money, anything irreversible, and how things look still go to him.
