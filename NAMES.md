# NAMES — what words mean here

The Chairman's shorthand, used across every product. This is its one home: a product's own `NAMES.md` keeps only that product's words.

- **Chairman** — Dhayan. Decides the customer problem, what a product does, prices and figures, visual acceptance, spending, permissions, anything irreversible. Works from an iPhone. Plain English only.
- **CTO** — the lead model, Claude or GPT, in any kind of session. Every technical decision. Never asks the Chairman a technical question.
- **Juku OS** — the way we build, not a product. Its words live in this repository, the rulebook.
- **build** — the only command word the Chairman types, in Cowork or CM: take the next ready item and move it on.
- **CM** — Claude code mode: a session at claude.ai/code started attached to one repository. Where building happens.
- **Cowork** — the Claude desktop/phone app session the Chairman talks in. It advises, changes words by pull request through the Mac, and has the hands.
- **CCE** — the Claude Chrome Extension: Claude driving the Chairman's own Chrome on the Mac — GitHub, Vercel, any website. Not "Claude Code".
- **The built-in browser** — the Claude app's own browser pane. Used for Claude's own pages and when CCE can't reach a site.
- **Hands** — a manual job no pipeline can do, done by Claude through CCE, computer use or the built-in browser. Never by the Chairman.
- **A slice** — one unit of work: a user-visible outcome with acceptance criteria.
- **Astra** — GPT-6 Astra, ChatGPT's strongest model. Only in the ChatGPT app's Work tab, which needs Work credits; the Chat tab's strongest is GPT-6 Pro. Asked for Astra when Work has no credits, use GPT-6 Pro and say so.
- **Fable** — Claude Fable, Anthropic's model used as a reviewer.
- **Architecture consensus** — the folder `Documents/Claude/Projects/Claude outputs` on the Chairman's Mac, where agreed Claude–ChatGPT consensus write-ups are saved. "Save it to architecture consensus" means save it there.
