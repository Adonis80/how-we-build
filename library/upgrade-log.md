# The upgrade log

Scope: this repository, and what it runs for every product. Open when: proposing an upgrade, or the Chairman asks what changed.

One line per upgrade, newest first: the date, what changed, why, its proof, and the pull requests (his ruling, 15 October 2026, [#222](https://github.com/Adonis80/how-we-build/issues/222)). A pull request that changes what runs — the gate's files, a workflow, the model registry, the product reads, or the Roadmap — adds its line here in the same pull request; `review-gate.py` holds it: red until the pull request changes this page, and the cold review reads that the change is its line. Words alone need none. A proof not yet shown says so, and its line is brought up to date when it is.
